# 船坞数据分析

## 页面与边界

「舰队管理 → 数据分析」统一提供共享船坞数据、心智分析和舰船科技分析。路由为 `/i/:instance/task/FleetAnalysis`，`tab=mind` 或 `tab=technology` 选择分析。旧心智和科技路由兼容跳转，两个分析标签保留各自草稿。

打开页面只读取本地配置，不调用设备或启动任务。用户点击「扫描船坞数据」时才执行手动 `DockScan`：回主界面清除隐藏搜索，进入船坞、重置筛选排序、回顶并逐页读取卡片。不觉醒、升级、突破、强化、退役、换船或战斗；遇到通用确认弹窗停止并保留旧快照。扫描仍遵循实例运行互斥，仅支持国服。

## 唯一扫描底账

`module/retire/dock_scan.py` 从原心智扫描提取页面稳定、三排行进、滚动配准、底部证明和有界复读，采用原科技群组身份目录。`MindCalculatorScan` 和 `FleetTechScan` 只保留为兼容入口，统一调用共享任务，工具菜单隐藏这些入口。

`DockScan.Dock.Result` 是按实例保存的共享底账。`ships` 保存按物理卡位去重的原始副本：群组身份、舰名、等级、基础稀有度、待核对与来源，以及本次扫描的行列位置。相同舰船的多个副本仍分别存在；卡位只用于本次扫描，不作为跨次人工校正的身份。底账不保存费用、人工排除或人工科技状态。

快照包含扫描范围、时间、底部与过滤证明、物理卡片数、OCR 船坞数量、完整性和版本摘要。`history` 只保存累计自动证据 `observed/current/absent`，不复制分析人工设置。提交在配置事务中完成，重新读取最新底账，拒绝覆盖扫描期间替换的新版本；取消、失败和内存不足不提交。

默认范围为 **1–125**，可选择局部范围。仅范围为 1–125、确认到底、过滤清除、实际卡片数与船坞数量一致且无待核对条目，才允许根据未读到确认缺失。局部或不确定扫描不会降低历史最高等级，也不会清空范围外记录。为证明早停而读到的范围外卡片保留在底账，分析层按范围筛选。界面将已保存快照覆盖范围与下一次扫描配置分开显示。

## 分析与人工设置

`module/runtime/dock_data.py` 提供纯数据投影。心智投影按确认群组转换为原心智目录的限定名，避免把两种「天城」「加贺」混为同一艘；确认副本按基础身份取最高，待核对项分别保留。原费用规则与特殊船计费排除不变。

`module/runtime/mind_analysis.py` 将人工差异保存在 `MindCalculatorScan.MindCalculator.Analysis`：按已确认群组保留排除、等级和基础稀有度覆盖、删除及额外录入。新扫描更新未人工覆盖的字段。待核对卡位的校正不跨扫描版本按行列套用，避免排序变化误改其他舰船。

科技从相同底账及累计自动证据生成本轮快照与历史进度，旧 `FleetTechScan.FleetTech.Record` 中人工覆盖、等级切换端点、阵营等级和历史继续保留。新科技编辑只保存人工分析字段，不复制扫描清单。心智计费排除不会改变科技持有状态，科技人工等级也不会修改心智或原始读数。

## 旧配置与接口

模板空 `{}` 不视为已扫描；显式 `ships: []` 是有效空快照，不回退复活旧扫描。没有共享快照时，两个分析仍各自读取原有记录，不在浏览时迁移落盘。数据源面板可展示有可信时间的较新旧快照，标注来源并始终不视作完整船坞。第一次显式共享扫描才写入新底账，旧字段作为兼容备份保留。

旧心智清单没有逐字段人工编辑历史。首次使用共享底账时继承可确认的排除、非默认基础稀有度与无自动扫描来源的手工录入；无法可靠区分的旧等级校正仍完整保存在旧清单，可手工核对，不能猜测并永久覆盖新扫描等级。

| 接口 | 行为 |
| --- | --- |
| `dock.report` | 返回源、时间、原始卡位、版本、完整性、待核对数和范围 |
| `dock.configure` | 仅保存下一次扫描等级范围，不改已有快照或启动游戏 |
| `tasks.run(DockScan)` | 使用既有任务运行互斥，显式启动共享扫描 |
| `mind.report/save` | 派生心智报告，人工保存仅写分析差异 |
| `fleetTech.report/patch` | 派生科技报告，人工编辑仅写科技设置 |
| `fleetTech.syncMind` | 旧客户端兼容；有共享底账后为无副作用的报告读取 |

API、服务与生成契约沿用现有登录、演示只读和实例隔离边界。报告与人工保存使用版本校验，过期编辑报冲突，不自动覆盖扫描或其他页面草稿。

## 验证

共享源和服务回归为 `tests.test_dock_data`、`tests.test_dock_service`；原截图、位移、排序、底部、失败保留与并发测试继续覆盖抽取后的扫描器。前端 `FleetAnalysis.test.tsx` 及 mock 浏览器验证统一入口、旧路由与查看不启动任务。所有自动验证使用隔离数据或已有截图，不连接真实游戏。
